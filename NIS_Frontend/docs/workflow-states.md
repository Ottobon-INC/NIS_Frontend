# Workflow State Machines

## 1. Contact (LinkedIn Ingestion to Intelligence)
* `NEW` (URL submitted)
* `PROCESSING` (Async scraping/enrichment via backend)
* `IDENTIFIED` (Basic profile parsed, awaiting Founder confirmation)
* `RESEARCHED` (Public signals scraped)
* `INTELLIGENCE_READY` (AI inference complete, Contact 360 fully populated)

## 2. Meeting (Preparation to Extraction)
* `SCHEDULED` (Future date, generating Brief)
* `PREPARING` (Brief ready for review)
* `CAPTURED` (Transcript uploaded, awaiting AI)
* `PROCESSING` (AI extracting problems/requirements)
* `EXTRACTED` (Needs detected, but not yet validated)
* `VALIDATION_REQUIRED` (Founder must Confirm/Reject)
* `VALIDATED` (Problems become Trusted Context)

## 3. Opportunity (Pipeline Lifecycle)
* `HYPOTHESIS` (AI proactively suggests gap)
* `VALIDATION_REQUIRED` (Needs Founder confirmation)
* `VALIDATED` (Confirmed by Founder)
* `SOLUTION_MATCHING` (Mapping to Knowledge Base)
* `PATH_DEFINED` (Buyer/Partner direction set)
* `PIPELINE` (Active on Opportunity Board)
* `OUTCOME` (Closed/Won/Lost/Feedback)

## 4. Introduction (Matching to Sent)
* `MATCH_FOUND` (Network map produces a hit)
* `FOUNDER_REVIEW` (Assessing "Why this match?")
* `APPROVED` (Match confirmed, routing to drafting)
* `MESSAGE_REVIEW` (Draft generated, awaiting edit/approval)
* `APPROVED_TO_SEND` (Finalized by Human)
* `SENT` (Outreach executed)
* `OUTCOME` (Accepted/Declined/Ignored)
